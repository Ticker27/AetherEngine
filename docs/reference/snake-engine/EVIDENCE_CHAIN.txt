# SNAKE Engine — เส้นทางการเชื่อมโยงการโหลดเกม (Chain of Evidence)

> **Provenance and scope:** this narrative combines static reverse-engineering notes with several distinct runtime-data sources. `docs/snake.zip` was a historical static package archive used only for the `assets/` and `res/` payload recorded in the extraction log. `docs/com.snake.zip` is a separately retained app-data snapshot, reviewed in [`RUNTIME_SNAPSHOT_REVIEW.md`](RUNTIME_SNAPSHOT_REVIEW.md); it is not an APK and contains no `.apk`, `.dex`, or `.so` members. Other sources cited below—such as `comsnake-live`, `com.snake_1.zip`, and `com.ninja.engine.zip`—are separate external inputs and must not be conflated with that retained ZIP. The retained snapshot records package metadata and persisted state, but does not independently establish a successful guest-game launch. The code-path narrative is an analyst interpretation, not proof of runtime success. This is a Snake-only analyst report, not an Aether implementation guide or evidence for 8 Ball Pool 56.30.0.

วันที่ตรวจสอบ: 2026-09-12 · Engine: Snake Engine v2.2.6 (`com.snake`) · เกมต้นแบบ: `com.miniclip.eightballpool`

## 3. รายงานข้อมูลจาก runtime-data snapshot ที่เก็บใน repo (`docs/com.snake.zip`)

> ตรวจ ZIP แบบอ่านสมาชิกในหน่วยความจำเมื่อ 2026-10-04 โดยไม่แตกไฟล์หรือคัดลอกเข้า Aether; รายการด้านล่างอ้าง path ภายใน prefix `com.snake/`. รายละเอียด checksum และขอบเขตการตรวจอยู่ใน [`RUNTIME_SNAPSHOT_REVIEW.md`](RUNTIME_SNAPSHOT_REVIEW.md). นี่เป็น snapshot ข้อมูลแอป ไม่ใช่ `docs/snake.zip` ซึ่งเป็น package archive ที่ใช้สกัด `assets/` และ `res/`.

| ไฟล์/ส่วน | สิ่งที่ตรวจยืนยันได้ | ขอบเขตการตีความ |
|---|---|---|
| `root/proc/0/cmdline` | บันทึกชื่อ `com.miniclip.eightballpool` (26 bytes) | เป็นข้อมูลใน snapshot ไม่ใช่หลักฐานเดี่ยวว่าการเปิด guest Activity สำเร็จ |
| `root/data/app/com.miniclip.eightballpool/package.conf` | binary metadata 173,904 bytes; มีชื่อ package, `EightBallPoolActivity`, `EightBallPoolApplication`, string `56.23.2` และ reference ไปยัง install path `base.apk` | APK ที่อ้างถึงไม่ใช่ ZIP member; review นี้ไม่ยืนยัน `versionCode` |
| `root/data/user/0/com.miniclip.eightballpool/` | มี persisted app data, WebView/cache, crash-report และ SDK-state files | ค่าและ identifiers ไม่ได้ถอดหรือคัดลอก; ให้ถือข้อมูลเป็น sensitive |
| `oat/arm64/Anonymous-DexFile@*.vdex` | มี 5 VDEX files ขนาด 108, 8,748, 156, 300 และ 156 bytes | เป็น VDEX cache records; ไม่ใช่ source DEX/APK และไม่พิสูจน์การ launch |

Inventory ของ ZIP ไม่มีสมาชิกนามสกุล `.apk`, `.dex` หรือ `.so`. ดังนั้นข้อความในรายงานเก่าที่ระบุ `versionCode=562310023`, พาธ APK จริง หรือไลบรารีเกม `libgame...`/PGL มาจากหลักฐานภายนอกและยังยืนยันจาก `docs/com.snake.zip` นี้ไม่ได้. SHA-256 ของ `package.conf` ใน ZIP นี้คือ `34afdbbe314935324e5cb5aa535e5ea8ef8fae042c82038b0e5279c160d60b6b`; ไม่ตรงกับ prefix `8ce5af64…` ที่รายงานเก่าอ้างให้ `comsnake-live`/`com.snake_1.zip`, จึงห้ามถือว่าเป็น snapshot เดียวกัน.

🔒 **ขอบเขตการแก้ไข:** `docs/com.snake.zip` คงเป็นหลักฐานแยกต่างหาก; ไม่มี member ใดถูกแตกหรือ port เข้า Aether. Snapshot มี app-private data และ SDK state จึงไม่ควรนำ raw values มาแสดงหรือทำสำเนาใน payload.
